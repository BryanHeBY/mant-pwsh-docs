Environment: Arch Linux `7.1.6-arch1-1` on x86-64, PowerShell 7.6.3
(`Core`, `Unix`), and ManT 0.6.0. ManT fetched the remote Git sources at
repository revision `43e1e9ddf58e571e66c9d954062f7db8df7584a7` and reported:

| Source | Documents |
| --- | ---: |

The complete portable release, strict content, concise-syntax, and upstream
checks passed for 390 documents. They exposed 3,594 semantic entries from 585
explicit declarations with no flagged content or option-entry gaps.

Remote-source ManT queries verified the current suffix and semantic models:

```text
mant pwsh7 --source pwsh7 --outline=sections --format json
mant iex --source pwsh7 --explain=-Command --format json
mant mrt.exe --source windows-tools --explain=/F:Y --format json
mant nfsadmin.exe --source windows-tools --explain=timeout= --format json
mant git --source cross-platform-tools --explain=status --format json
```

At the then-tested revision, the excerpts resolved to `-Command`, `/F:y`
(through the insensitive `/F:Y` selector), `timeout=`, and the `git status`
command entry. This evidence predates the ManT v6 fixed-attached-value
migration; the 0.6.0 release check must replace the normalized `/F:y` result
with the canonical `/F:Y` entry described below.

## ManT 0.6 protocol migration evidence — 2026-08-12

The current ManT development binary reported `mant.cli/v6`, native API version
6, and v6 request, query, document, outline, excerpt, and search schemas. The
portable validator passed all 390 published documents. The strict content
audit reported 3,644 semantic entries from 591 declarations with no flags,
and the concise-syntax audit found no option-entry gaps in 59 documents.

Direct file queries confirmed that `attached=fixed` preserves `/F:Y` and
`perf=default` as exact option names. A `role=variable` outline exposed 19
automatic-variable entries, including `$?`, `$$`, `$^`, and
`$LASTEXITCODE`; explaining `$LASTEXITCODE` returned the corresponding
variable excerpt without diagnostics. Remote-source confirmation remains part
of the platform release run after this documentation revision is published.
